## 核心结论

### 封号根因（确定性排列）
1. **多用户行为聚合（45%）** — 多人共享 token，请求密度/主题分散度异常
2. **model-family 格式破坏（30%）** — Go 网关中转导致指纹断裂、参数丢失
3. **API 调用模式异常（15%）** — 缺少初始化序列、伴随流量
4. **消费量异常（10%）** — 单 token 20 小时高强度使用

### 纳什均衡点
- 蓝队：无法 100% 检出单用户+编程用途场景（检出率 < 15%）
- 红队：无法在多用户共享模式下安全运营（检出率 > 80%）
- 均衡：反代从"省钱工具"退化为"兼容性网关"

### 最有价值的五个洞察
1. 经济学是终极武器 — 迫使 1:1 模式后反代商业模型崩溃
2. 多用户行为有信息论极限 — 无法在不降低吞吐的前提下完全消除
3. 中间层是最大检测放大器 — model-family 的存在放大了所有检测信号
4. 误报边界是守方天花板 — 正常用户的保护限制了检测激进度
5. 内容是最后的不可伪装信号 — RP/非编程内容无法包装成 Claude Code 场景
